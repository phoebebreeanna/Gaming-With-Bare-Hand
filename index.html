01 · Overview

Computer vision, mapped to muscle memory.

Built from the ground up to make gesture-controlled gaming feel as immediate as a keyboard - without the cost or friction of dedicated hardware.

Gaming with Bare Hands is a desktop application that lets players control PC games using only the gestures of their hands, captured through any standard webcam.

A MediaPipe pipeline locates 21 keypoints on each hand in real time. Those keypoints feed a custom PyTorch classifier trained to recognize the gestures players actually want to perform - open palms, fists, points, pinches. Each gesture is then mapped to a game input through PyAutoGUI, with calibration, multi-hand support, and visual feedback baked in.

The result is a controller that lives in your hands, free of plastic, sensors, or accessories.

03 · Pipeline

From a frame of video to a keystroke - in five stages.

The system is built in Python on top of OpenCV for capture, MediaPipe for landmark detection, PyTorch for classification, PyAutoGUI and pynput for input emulation, and PySide6 for the desktop interface.

import torch
import torch.nn as nn

class GestureNet(nn.Module):
    # 21 landmarks × (x,y,z) + frame delta = 126 features
    def __init__(self, input_size, num_classes):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(input_size, 256), nn.BatchNorm1d(256), nn.ReLU(), nn.Dropout(0.3),
            nn.Linear(256, 128),        nn.BatchNorm1d(128), nn.ReLU(), nn.Dropout(0.3),
            nn.Linear(128, 64),         nn.BatchNorm1d(64),  nn.ReLU(), nn.Dropout(0.2),
            nn.Linear(64, num_classes)
        )

    def forward(self, x):
        # x: tensor of shape (batch, 126)
        return self.net(x)
